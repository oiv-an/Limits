# История версий

## 1.2.0

- Удалены запросы Touch ID и обязательная разблокировка после сна, блокировки экрана и перезапуска.
- Вход Claude сохраняется локально; сессия автоматически продлевается.
- Подключение через браузер больше не требует установки Claude Code и доступа к связке ключей.
- Существующий вход переносится без диалогов, когда у него уже разрешён такой доступ.
- При потере интернета подключение сохраняется, временная ошибка не требует повторного входа.

## 1.1.0

- Готовый универсальный установщик DMG для Apple Silicon и Intel.
- Первое окно настройки с автозапуском и плавающей панелью.
- Компактные иконки, оба лимита Claude через слэш и время до сброса.
- Вход Claude через обычный браузер с Google, Apple или email.
- Разблокировка подключения Claude через Touch ID без фоновых запросов пароля.
- Автоматические тесты, сборка установщика и проверка контрольной суммы на GitHub.

### Установка

Откройте `Limits-1.1.0-universal.dmg`, перетащите `Limits.app` в `Applications` и запустите установленную копию.

Проект пока не имеет сертификата Apple Developer ID. При первом запуске нажмите на `Limits.app` правой кнопкой, выберите «Открыть» и подтвердите запуск. После получения сертификата тот же сценарий сборки поддерживает подпись и нотариальное заверение Apple.

# Limits

Небольшое нативное приложение для macOS 14+ на Swift / SwiftUI / AppKit. Работает в строке меню без значка в Dock.

## Как пользоваться

Откройте `Limits.app`. Рядом с часами появятся иконки сервисов с остатками лимитов. У Claude показаны два значения через слэш, например `9/42%`: сначала 5 часов, затем неделя. Под процентами — время до сброса в том же порядке.

- Нажатие на индикатор открывает периоды лимитов, остаток в процентах и время до сброса. Точное время сброса видно при наведении.
- У Codex показан наименьший остаток среди общих периодов выбранного лимита и время его сброса. У Claude всегда сохранён порядок `5 часов / неделя`. Отдельные модельные лимиты раскрываются кнопкой «Ещё лимиты».
- Кнопка булавки включает небольшую панель поверх окон. Перетаскивайте её за свободное место слева. Положение сохраняется.
- В настройках можно выбрать обновление раз в 2, 5 или 10 минут, лимит Codex для строки меню и автозапуск. По умолчанию обновление раз в 5 минут, автозапуск выключен.
- Точка после процента означает сохранённые данные. При ошибке показывается её описание. Отсутствующее значение отображается как «—». После времени сброса приложение ждёт подтверждённые данные.

## Подключение

**Codex:** используется установленное приложение Codex (либо локальный `codex`) и его текущий вход ChatGPT. Limits вызывает только `initialize`, `initialized` и `account/rateLimits/read` через короткоживущий локальный App Server. Задачи и запросы к модели не создаются. Токены Codex приложение не читает и не копирует.

**Claude:** нажмите «Подключить Claude». Limits откроет официальный вход Claude в обычном браузере. Выберите Google, Apple или email и завершите авторизацию. Встроенный WebKit-браузер из предыдущих версий удалён: Google не поддерживает такой способ входа.

Используется команда `claude auth login --claudeai` официального компонента Claude Code. Она сама открывает браузер, принимает обратный переход и сохраняет подключение. Если браузер вместо возврата покажет код, вставьте его в защищённое поле окна Limits. Код и URL авторизации не записываются в журналы. При отмене или завершении Limits процесс входа останавливается.

Если компонент уже установлен, Limits использует его. Иначе загружает нативный файл с `downloads.claude.ai`, проверяет SHA-256 и размер по официальному манифесту и сохраняет его в `~/Library/Application Support/pro.ivol.Limits/Tools/claude`. Компонент занимает примерно 200 МБ, отдельно от самой панели. Настройки оболочки и PATH не меняются.

После входа подключение разблокируется через Touch ID. Используется только биометрическая проверка без перехода к вводу пароля; при отмене или недоступном Touch ID автоматических повторов нет. Нажмите «Разблокировать Touch ID» в панели. После запуска или блокировки Mac подключение нужно разблокировать снова. Фоновое обновление использует только токен в памяти и никогда не читает связку ключей.

При первом переносе после Touch ID читается только `claudeAiOauth.accessToken` из стандартного файла либо записи `Claude Code-credentials`. Для старой записи используется системная утилита, которой эта запись уже доверяет, только при разблокированной связке ключей. ACL исходной записи не меняется. Затем токен хранится зашифрованным AES-GCM; ключ расшифрования защищён Secure Enclave и текущим набором отпечатков. В файл попадают только шифротекст, публичные параметры и аппаратно обёрнутый ключ. Смена отпечатков требует повторного подключения.

Запросы лимитов идут только на `api.anthropic.com`. Для входа используется подписка Claude, а не отдельный API-биллинг. Запросы к модели не создаются. Истёкшую сессию можно обновить кнопкой «Войти в Claude…».

Для Claude используются внутренние сервисные методы чтения лимитов, а не публичный стабильный API. При изменениях со стороны Claude адаптер может потребовать обновления. При 429 запросы приостанавливаются минимум на 5 минут; положительный `Retry-After` учитывается. Ручное обновление не обходит эту паузу.

## Хранение

Настройки: стандартные preferences `pro.ivol.Limits`. Кэш содержит только последние проценты, периоды и время обновления в `~/Library/Application Support/pro.ivol.Limits/usage-cache.json` с правами `600`. Исходный вход Claude хранится официальным компонентом Claude Code в Keychain (либо его стандартном файле учётных данных). Зашифрованное подключение Limits хранится рядом с кэшем в `claude-touch-id.json` с правами `600` и доступно только с Touch ID на этом Mac. `touch-id-state.json` содержит только результат разблокировки, время и код ошибки, без секретов. Аналитики, серверной части и внешних зависимостей нет.

## Сборка

Нужны Xcode / Command Line Tools со Swift 6.0+.

```sh
./scripts/build.sh
swift test --disable-sandbox
```

Готовое приложение: `dist/Limits.app`. Сборка выполняется для архитектуры текущего Mac; на машине разработки это Apple Silicon (arm64). Приложение имеет локальную ad-hoc подпись, не предназначенную для массового распространения. Для автозапуска используйте установленную копию в `~/Applications` или `/Applications`.

Проверка Codex из приложения:

```sh
./dist/Limits.app/Contents/MacOS/Limits --check-codex
```

Проверка подключений и рендер самого интерфейса (не захват экрана):

```sh
./dist/Limits.app/Contents/MacOS/Limits --smoke-test "$PWD/verification"
```

`verification/smoke-result.json` содержит результат проверки; PNG рядом показывают реальные данные этого запуска. Claude без входа корректно показывает состояние подключения. Успешное чтение реального аккаунта Claude требует завершённого входа и отдельно отмечается в отчёте.

В версии 1.0.4 добавлена защита подключения через Touch ID и исключены обращения к связке ключей при фоновом обновлении. В версии 1.0.2 встроенный вход заменён официальной авторизацией в системном браузере. Тесты проверяют извлечение допустимого адреса входа, шифрование подключения и расчёт лимитов; действительное подключение подтверждается только после успешного входа пользователя.

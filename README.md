# Limits

Небольшое нативное приложение для macOS 14+ на Swift / SwiftUI / AppKit. Работает в строке меню без значка в Dock.

## Установка готовой версии

Скачайте `Limits-1.2.0-universal.dmg` из [последнего релиза](https://github.com/oiv-an/Limits/releases/latest), откройте образ и перетащите `Limits.app` в `Applications`. Запустите установленную копию из папки «Программы». При первом запуске появится небольшое окно, где можно включить автозагрузку и плавающую панель.

Сборка универсальная: один файл работает на Mac с Apple Silicon и Intel. Для готовой версии пока используется локальная подпись, потому что у проекта нет сертификата Apple Developer ID. Если macOS покажет предупреждение, нажмите на `Limits.app` правой кнопкой, выберите «Открыть» и подтвердите запуск. Последующие запуски проходят обычно.

## Как пользоваться

Откройте `Limits.app`. Рядом с часами появятся иконки сервисов с остатками лимитов. У Claude показаны два значения через слэш, например `9/42%`: сначала 5 часов, затем неделя. Под процентами — время до сброса в том же порядке.

- Нажатие на индикатор открывает периоды лимитов, остаток в процентах и время до сброса. Точное время сброса видно при наведении.
- У Codex показан наименьший остаток среди общих периодов выбранного лимита и время его сброса. У Claude всегда сохранён порядок `5 часов / неделя`. Отдельные модельные лимиты раскрываются кнопкой «Ещё лимиты».
- Кнопка булавки включает небольшую панель поверх окон. Перетаскивайте её за свободное место слева. Положение сохраняется.
- В настройках можно выбрать обновление раз в 2, 5 или 10 минут, лимит Codex для строки меню и автозапуск. По умолчанию обновление раз в 5 минут, автозапуск выключен.
- Точка после процента означает сохранённые данные. При ошибке показывается её описание. Отсутствующее значение отображается как «—». После времени сброса приложение ждёт подтверждённые данные.

## Подключение

**Codex:** используется установленное приложение Codex (либо локальный `codex`) и его текущий вход ChatGPT. Limits вызывает только `initialize`, `initialized` и `account/rateLimits/read` через короткоживущий локальный App Server. Задачи и запросы к модели не создаются. Токены Codex приложение не читает и не копирует.

**Claude:** нажмите «Подключить Claude», выберите Google, Apple или email в обычном браузере и завершите вход. Limits сам сохранит подключение. Вводить API-ключи, пароль Mac или подтверждать Touch ID не требуется.

Подключение сохраняется после сна, блокировки экрана и перезапуска приложения. Срок действия сессии продлевается автоматически. Если Claude отозвал разрешение, приложение предложит подключить аккаунт заново; браузер самостоятельно не открывается.

Вход использует OAuth с PKCE и проверкой `state`, обратный переход принимается только на локальном интерфейсе. Дополнительный компонент Claude Code больше не скачивается и не запускается. Коды и адреса авторизации не журналируются. При обновлении предыдущей версии существующий вход переносится автоматически, если к нему уже есть доступ без системного запроса. Старые файлы Touch ID удаляются после успешного получения лимитов, исходный вход Claude Code не изменяется.

Запросы лимитов идут только на `api.anthropic.com`, продление входа — на `platform.claude.com`. Для входа используется подписка Claude, а не отдельный API-биллинг. Запросы к модели не создаются.

Для Claude используются внутренние сервисные методы чтения лимитов, а не публичный стабильный API. При изменениях со стороны Claude адаптер может потребовать обновления. При 429 запросы приостанавливаются минимум на 5 минут; положительный `Retry-After` учитывается. Ручное обновление не обходит эту паузу.

## Хранение

Настройки: стандартные preferences `pro.ivol.Limits`. Кэш содержит только последние проценты, периоды и время обновления в `~/Library/Application Support/pro.ivol.Limits/usage-cache.json` с правами `600`. Подключение хранится рядом в `claude-session.json`: access token, refresh token, срок действия и разрешения OAuth. Это локальный файл без дополнительного шифрования: доступ разрешён только текущему пользователю Mac (`600`, каталог `700`). Сохранение атомарное. Limits больше не использует собственные ключи шифрования, Secure Enclave или биометрическую разблокировку. Аналитики, серверной части и внешних зависимостей нет.

## Сборка

Нужны Xcode / Command Line Tools со Swift 6.0+.

```sh
./scripts/build.sh
swift test --disable-sandbox
```

Готовое универсальное приложение: `dist/Limits.app`. Оно содержит `arm64` и `x86_64`. Без переменной `LIMITS_CODESIGN_IDENTITY` используется локальная ad-hoc подпись. Для Developer ID-сборки передайте имя сертификата через эту переменную. Если также задан профиль `LIMITS_NOTARY_PROFILE`, сценарий упаковки отправит образ на нотариальную проверку Apple и прикрепит результат.

Установочный образ и контрольная сумма:

```sh
./scripts/package-release.sh
```

Готовые файлы появятся в `release/`. Образ содержит `Limits.app`, ссылку на `Applications` и короткую инструкцию.

Проверка Codex из приложения:

```sh
./dist/Limits.app/Contents/MacOS/Limits --check-codex
```

Проверка подключений и рендер самого интерфейса (не захват экрана):

```sh
./dist/Limits.app/Contents/MacOS/Limits --smoke-test "$PWD/verification"
```

`verification/smoke-result.json` содержит результат проверки; PNG рядом показывают реальные данные этого запуска. Claude без входа корректно показывает состояние подключения. Успешное чтение реального аккаунта Claude требует завершённого входа и отдельно отмечается в отчёте.

В версии 1.2.0 удалена обязательная разблокировка через Touch ID. Тесты проверяют восстановление входа после перезапуска, автоматическое продление, сохранение обновлённого refresh token, работу при потере сети, смену аккаунта во время запроса, OAuth callback и расчёт лимитов.
